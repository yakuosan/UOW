# ヒーリング音楽ファイル

以下の3つのMP3ファイルをここに配置してください。

## 必要なファイル

- `healing_low.mp3` — 注意レベル用（穏やかな音楽）
- `healing_mid.mp3` — 警告レベル用（中程度のヒーリング音楽）
- `healing_high.mp3` — 危険レベル用（フルボリューム用ヒーリング音楽）

## 著作権フリー素材の入手先

- [Pixabay Audio](https://pixabay.com/music/)
- [FreeSound](https://freesound.org/)
- [Free Music Archive](https://freemusicarchive.org/)

## 注意事項

- 実機テスト前に必ずファイルを追加してください
- ファイルが存在しない場合、音楽再生はスキップされますがアプリは正常動作します
- Xcodeプロジェクトに追加後、「Copy items if needed」にチェックを入れてください
